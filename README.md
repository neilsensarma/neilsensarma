## 🚀 Featured Projects

### 🧠 [Cancer Bioinformatics RAG System](https://github.com/neilsensarma/cancer_rag_llm)

A domain-specific Retrieval-Augmented Generation system designed to answer scientific questions using biomedical literature.

- Built a knowledge base from approximately **860 open-access biomedical research papers**.
- Implemented semantic retrieval using **Sentence Transformers** and **ChromaDB**.
- Integrated cross-encoder reranking to improve document relevance.
- Deployed a quantized **Llama 3.1 8B Instruct** model locally using **llama.cpp**.
- Developed a citation-aware generation pipeline using PubMed identifiers and document metadata.

**Tech:** Python · Llama 3.1 · llama.cpp · ChromaDB · Sentence Transformers · Cross-Encoders · PubMed/PMC

### 🧬 [Single-Cell Analysis of Pancreatic Cancer](https://github.com/neilsensarma/SingleCellAnalysis-PrePostChemoPDAC)

A reproduction and exploratory analysis of single-cell RNA sequencing data from pancreatic ductal adenocarcinoma (PDAC) patients before and after chemotherapy.

- Processed patient-level scRNA-seq datasets using **Seurat**.
- Performed quality control, normalization, batch integration, dimensionality reduction, and clustering.
- Identified cell populations using canonical marker genes and differential expression analysis.
- Investigated cellular heterogeneity and tumor microenvironment composition across treatment groups.

**Tech:** R · Seurat · scRNA-seq · UMAP · Clustering · Differential Expression · Data Visualization

### 🔥 [Wildfire Occurrence Prediction (WiFOP)]:(https://github.com/neilsensarma/WiFOP.git)

A machine learning project exploring wildfire occurrence prediction using environmental and geospatial features.

- Explored predictive modeling for a challenging, imbalanced classification problem.
- Applied feature engineering, classification algorithms, and model evaluation.
- Evaluated predictive performance using ROC-AUC and precision-recall metrics.

**Tech:** Python · scikit-learn · Machine Learning · Data Analysis
